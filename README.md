# ISO-27001-Suite

> A simple, web-based toolkit to practice and perform ISO/IEC 27001 gap analysis and maturity assessments.

---

## 🚀 Quick start

- ✅ No backend, no installation.
- ✅ Works directly in your browser.
- ✅ Great for learning ISO 27001 and doing quick self-assessments.

```bash
# Clone the repo
git clone https://github.com/Echo506/ISO-27001-Suite.git

cd ISO-27001-Suite

# Open the main tool in your browser (double-click in your file explorer)
gap-analysis.html
```

---

## 🧩 What is this project?

ISO-27001-Suite is a **lightweight toolkit** focused on helping you understand where you stand against ISO/IEC 27001 and what needs to improve.

You can use it to:

- Capture ISO 27001 requirements and controls.
- Record your current implementation level and evidence.
- Visualize gaps and build a remediation plan.

It is intentionally simple: everything runs in the browser so you can use it for learning, labs, or small internal assessments.

## 👥 Who is this for?

This project is designed for:

- Security analysts and IT admins doing quick ISO 27001 self-checks.
- Students and juniors learning about ISO 27001 and ISMS basics.
- Consultants who want a lightweight, no-friction tool for workshops.

You don't need to be an ISO 27001 expert to start using it.

---

## 📌 Main features

- Gap analysis view for ISO 27001 requirements and controls.
- Fields for:
  - Control / requirement ID and description.
  - Implementation level (e.g., 1–5).
  - Evidence and comments.
- Basic summary of gaps to support your remediation plan.

> 🔎 Tip: You can start with fictional companies (lab scenarios) to practice before working on a real environment.

---

## 📚 How to use it (step by step)

1. **Download or clone** this repository.
2. **Open** `gap-analysis.html` in your browser.
3. **Enter your data**:
   - Organization name and scope.
   - Controls / requirements you want to assess.
   - Current implementation level and evidence.
4. **Review the results**:
   - Identify low scores (biggest gaps).
   - Decide which actions you need to take first.
5. **Export or copy** your results to your own documentation or reports.
